# TP1 - Développement collaboratif et Open Science

## 1. Objectif du projet

Ce projet a pour objectif de mettre en pratique les outils de développement collaboratif et les principes de l'Open Science à travers Git et GitHub.

Il vise également à organiser un projet scientifique de manière reproductible.

## 2. Auteurs

- Étudiant A : zellal nour elhouda
- Étudiant B : mokhtar benali imene nour elhouda 

## 3. Description du projet

Ce projet porte sur l'étude de la croissance bactérienne en fonction du temps et de la température.

Les données expérimentales seront utilisées pour réaliser une analyse statistique et des représentations graphiques.

## 4. Organisation du projet

- `data/raw/` : données brutes.
- `data/processed/` : données nettoyées.
- `notebooks/` : notebooks Jupyter.
- `scripts/` : scripts Python.
- `results/` : résultats et graphiques.

## 5. Reproductibilité

Le projet utilise Python et les bibliothèques scientifiques nécessaires à l'analyse des données.

L'environnement logiciel est décrit dans le fichier `environment.yml`.
